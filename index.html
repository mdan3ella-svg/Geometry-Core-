Vertascan Geometry Core
A dependency-free prototype for parametric mesh creation, orthographic drafting and interchange. Designed as a foundation for future exact CAD and BIM kernels.
Choose a primitive, edit dimensions and placement in the inspector, select objects in the viewport or hierarchy, and save the editable project. Front looks along −Y, right along −X, top along −Z. Orbit returns to an axonometric view. SVG and DXF export the current projected edges, not certified drawings. OBJ, STL and GLB export triangulated geometry.
CORE modules include sampled rational B-spline surfaces, lofts, sweeps, worker mesh operations, limited dimensional constraints, BIM metadata and regenerated drawing sheets. Exact B-rep, IFC exchange, full constraint solving and GPU/path-traced rendering are not integrated. No network or CDN is required.
